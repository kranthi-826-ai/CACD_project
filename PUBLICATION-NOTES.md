# Repository contents

This repository contains the AI Enabled DevSecOps Framework for Adaptive Quantum Resilient Software Systems project source, tests, configuration examples and research documentation.

- Start with [the presentation overview](README-PRESENTATION.md) for the workflow, components and demonstration explanation.
- The exact user-supplied downloaded paper is [Research_Paper.pdf](research%20paper/Research_Paper.pdf). It is copied unchanged; its title and content have not been rewritten for this upload.
- Editable paper sources are under `docs/research/paper/`. The separately reviewed PDF under that directory may be a different revision from the downloaded paper requested for this upload.
- Real passwords, private runtime settings, database volumes, downloaded datasets, trained model binaries, dependencies, temporary files and generated root output bundles are intentionally excluded.
- A fresh clone needs private configuration, an appropriate retained model artifact and locally built images before the complete application can run. The laptop-only `.runtime` startup configuration is not included.
- Screenshot bundle paths mentioned in the presentation guide refer to local generated outputs and are not included in this publication.
- Historical verification reports are not proof that this repository is currently deployed, that dependency advisories are resolved or that an ML accuracy target has been achieved.

This publication does not modify the original AI-PQC-Security repository or its remote configuration.
